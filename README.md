# medazizktata/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install medazizktata/tap/sudoorbell
sudoorbell install
```

| Formula | What it is |
|---|---|
| [sudoorbell](https://github.com/medazizktata/sudoorbell) | Approve `sudo` from AI agents and other tools that have no terminal: a dialog, Touch ID or a terminal prompt naming the command. |
